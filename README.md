## How to Use

1. Launch the application.
2. Focus the window you want to pin.
3. Press **Ctrl + Space**.
4. The window will stay above all others.

Press the hotkey again to unpin it.

---

## System Requirements

- Windows 10 or newer
- .NET Desktop Runtime (if required)
